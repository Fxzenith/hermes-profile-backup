# Alex Hormozi Advisor — usage

In this profile's chat, invoke the advisor with the slash command:

  /hormozi <your question, draft request, or brainstorm prompt>

Examples:
  /hormozi what is the CLOSER framework?
  /hormozi draft a 3-email sequence selling a $2k coaching offer
  /hormozi brainstorm lead magnet ideas for a fitness coach

The bot retrieves relevant notes from GBrain (experts/alex-hormozi/), answers
only from those, cites note slugs, and marks application with [inference].
Local CLI equivalent: /root/hormozi_bot/hormozi_bot.py ask|draft|brainstorm "<q>"
