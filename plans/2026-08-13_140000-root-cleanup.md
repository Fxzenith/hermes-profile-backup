# Root Directory Cleanup and Organization Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Clean up the cluttered /root directory by removing temporary test files, archiving old project artifacts, and organizing active work into logical category folders.

**Architecture:** 
- **Identify:** Categorize files into "Active Project", "Archive", "Temporary/Trash", and "Configuration".
- **Structure:** Create a standard directory layout (e.g., `projects/`, `archives/`, `lab/`, `assets/`).
- **Execute:** Move files to their new locations, delete verified junk, and update relevant environment paths if necessary.

**Tech Stack:** Standard Linux shell commands (find, mv, rm, mkdir).

**Objective:** Establish the new folder hierarchy to receive the root content.

- **Broken Paths:** If any cron jobs or scripts rely on absolute `/root/filename` paths, they will break. 
    - *Mitigation:* No active cron jobs were found depending on moved files; Hermes memory provider remains functional via symlink.
- **Environment Variables:** If `PATH` or project-specific envs point to root, they need updating.
    - *Mitigation:* The gbrain symlink ensures CLI workflows continue to work; no other envs were identified as needing update.
- **gbrain Sync:** The memory provider (gbrain) is at `/root/projects/gbrain`. Moving it required updating the symlink and verifying the Hermes gbrain plugin still works (it does via the symlink).
